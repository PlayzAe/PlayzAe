### Stuff I've built

**01. [Arena Desktop](https://github.com/PlayzAe/arena.ai-desktop)**

<img src="https://img.shields.io/github/stars/PlayzAe/arena.ai-desktop?style=flat-square&color=f0532c" />
<img src="https://img.shields.io/github/forks/PlayzAe/arena.ai-desktop?style=flat-square&color=f0532c" />

An unofficial Windows desktop client for [arena.ai](https://arena.ai/).

I wanted more than another browser tab, so I built an actual desktop application with WebView2, a local Python backend, workspace integration and an AI agent capable of interacting with local files.

- 100+ models, multiple chat modes and account switching.
- Local file access, editing and command execution.
- MCP server integration.
- Streaming agent responses and tool execution.

**A browser tab is a product decision, not a law of physics.**

I don't know why an official desktop client isn't a priority for Arena, but I wanted one. So I built it. Consider this an open-source middle finger to settling for less.

[Source Code](https://github.com/PlayzAe/arena.ai-desktop) · [Windows Download](https://github.com/PlayzAe/arena.ai-desktop/releases)

*Unofficial project. Not affiliated with Arena AI.*
